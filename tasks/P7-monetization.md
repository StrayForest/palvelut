# P7 — Paid visibility (gated)

Blocked until P6 records **GO** and provider interviews confirm willingness to pay.

## Shape before build

- Choose subscription vs time-boxed placement from evidence; no service commission.
- Define organic ranking protection, `Sponsored` labels, inventory caps, refunds and invoice/VAT treatment.
- Select the payment provider after Finnish business/accounting review.
- Add entitlements behind an interface; do not entangle billing state with profile publication.

## Accept

- Free profiles remain useful and contactable.
- Sponsored placement is explicit and cannot occupy all visible results.
- Webhook processing is signed, idempotent and replay-safe.
- Failed/cancelled payment has a documented grace/entitlement transition.
- Revenue, refunds and VAT evidence reconcile with provider records.

No implementation is authorized by this task until the gate is recorded.
