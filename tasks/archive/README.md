# Task archive

Historical records for completed atomic delivery steps.

Create one short file only after the step's relevant checks pass. Keep active work in `tasks/Px-*.md`; do not duplicate unfinished scope here.

Suggested record:

```md
# Px-NN — <step>

Completed: YYYY-MM-DD
Commit/PR: <exact reference when available>

## Scope
- <what was completed>

## Checks
- `<command/check>` — PASS

## Deviations
- None.
```
