# Finrix Palvelut

Production-first каталог специалистов, с которыми можно говорить по-русски в Финляндии.

## Решение

- mobile-first сайт, не native-приложение;
- каталог и прямой контакт, не marketplace;
- первый рынок: Helsinki, Espoo, Vantaa;
- бесплатное размещение до подтверждения спроса;
- проверяем факты о специалисте, но не обещаем качество его работы;
- модульный Django-монолит с PostgreSQL.
